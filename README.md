# EBAC_Projeto06_ex-efood

## Sobre o Projeto

O **EBAC_Projeto06_ex-efood** é uma aplicação desenvolvida com Create React App utilizando TypeScript, projetada para simular uma experiência de navegação em um aplicativo de pedidos de comida.
---

## Tecnologias e Ferramentas

- **React**
- **TypeScript**
- **HTML**
- **ESLint**
- **Prettier**
- **Create React App**
